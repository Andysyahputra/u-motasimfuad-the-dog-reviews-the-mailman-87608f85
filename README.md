An entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85) "The Dog Reviews the Mailman" bounty. `main.ts` (Node 22, standard library only) writes one funny one-line review a dog gives the mailman to `/output/entry.txt`:

> One star. He comes every day, teases me through the fence, and leaves. I have filed 400 complaints with the post office. They keep delivering them to him.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`. The output is deterministic: two runs write byte-identical files.
